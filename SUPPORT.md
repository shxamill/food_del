# Support

## Getting help

- Open a Bug report for a reproducible frontend, admin, or API problem.
- Open a Feature request for a focused improvement.
- For setup issues, include your Node.js version, operating system, application directory, command, and exact error.

Check the root README and existing issues first. For API issues, include the route and a redacted request/response example. For UI issues, include browser and viewport details.

Never post passwords, API keys, payment secrets, database connection strings, customer data, or unredacted logs. For security concerns, follow SECURITY.md. Support is provided on a best-effort basis.
